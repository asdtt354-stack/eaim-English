시작 전 준비

Gemini API 키 설정 · 최초 1회만 하면 됩니다
🔑 Gemini API 키가 필요한 이유

EAIM 영어 플랫폼의 AI 단어 도우미, AI 첨삭, AI 회화 기능 모두 Google Gemini 2.5 Flash 모델을 사용합니다. API 키가 없어도 기본 게임과 문장 만들기는 사용 가능하지만, AI 기능은 키가 필요합니다.

💡

무료로 사용 가능해요!

Google AI Studio의 무료 티어로 수업에 충분히 활용할 수 있습니다. 별도 결제가 필요하지 않아요.

📋 API 키 발급 방법

Google AI Studio 접속

브라우저에서 아래 주소로 이동합니다. Google 계정으로 로그인하세요.

https://aistudio.google.com

"Get API key" 클릭

왼쪽 사이드바 또는 상단 메뉴에서 Get API key → Create API key를 클릭합니다.

키 복사

AIzaSy...로 시작하는 긴 문자열을 복사합니다. 이 키를 안전하게 보관하세요.

플랫폼에 입력

각 앱에서 선생님이신가요? → 교사 패널 → Gemini API 키 항목에 붙여넣기 후 저장합니다. 저장하면 브라우저에 기억되어 다음에 다시 입력하지 않아도 됩니다.

⚠️

API 키 주의사항

API 키는 개인 정보입니다. 공개 게시물이나 SNS에 올리지 마세요. 학생용 기기에는 선생님이 직접 입력해 주세요.

영어 놀이터 사용법

eaim-english-playground.html · Step 1~5 단계별 문장 만들기
🚀 시작하기

앱을 열면 이름 입력 화면이 나타납니다. 이름을 입력하고 "시작하기!"를 누르면 활동이 시작됩니다. 입력된 이름은 교사 컨트롤 패널의 학생 현황에 자동으로 나타납니다.

❤️

감정 고르기 공통

오늘의 감정(Happy, Sad, Excited 등 10가지)을 선택하면 자동으로 I feel happy. 형태의 기본 문장이 완성됩니다.

📝

Step 1 — 뼈대 문장 WHO + ACTION + WHAT

주어(WHO), 동사(ACTION), 목적어/보어(WHAT)를 선택하거나 직접 입력해 기본 문장을 만듭니다. 시제(현재·과거·미래)를 선택하면 동사가 자동으로 변형됩니다.

🔗

Step 2 — 문장 이어붙이기 접속사

because, when, but, and, so 중 접속사를 골라 두 번째 절을 연결합니다. 앞 문장이 자동으로 불러와집니다.

✨

Step 3 — 꾸미기 Where / How / When

장소(at school), 방법(happily), 시간(yesterday)을 추가해 문장을 풍부하게 만듭니다. 완성된 문장은 저장 버튼으로 이야기에 추가할 수 있습니다.

🌳

Step 4 — 심화 레벨업 관계대명사

who, which, that, to 버튼을 눌러 관계대명사절을 삽입합니다. 심화 레벨 학생 전용입니다.

🏆

Step 5 — 완성 & AI 첨삭 My Story

저장된 문장들이 나열됩니다. AI 선생님의 첨삭! 버튼을 누르면 Gemini가 시제 검토, 교정, 격려 피드백을 해줍니다. 인쇄 및 텍스트 저장도 가능합니다.

🔊 TTS 듣기 기능

각 Step의 완성된 문장 아래 Listen! 버튼을 누르면 영어 TTS(Text-to-Speech)로 원어민 발음을 들을 수 있습니다. 브라우저 내장 기능으로 별도 설치가 필요 없습니다.

💡

크롬 브라우저 추천

TTS 기능은 크롬(Chrome) 브라우저에서 가장 자연스럽게 작동합니다. iOS Safari도 지원합니다.

교사 컨트롤 패널

두 앱 모두 동일한 방식 · 기본 비밀번호: 1234
🔐 교사 패널 접속 방법

이름 입력 화면에서

학생 이름 입력 모달 하단의 "선생님이신가요?" 링크를 클릭합니다.

비밀번호 입력

기본 비밀번호 1234를 입력합니다. 패널 내에서 변경 가능합니다.

교사 패널 사용

API 키 설정, 수업 ON/OFF, 레벨 고정, 학생 현황 확인이 가능합니다.

⚙️ 교사 전용 기능 목록
🔑

API 키 관리

Gemini API 키 입력 및 저장. 한 번 저장하면 브라우저가 기억합니다.

🟢

수업 ON/OFF

수업 종료 시 학생 화면에 잠금 메시지를 표시합니다. (놀이터 전용)

🔒

레벨 고정

기초·중급·심화 중 하나로 전체 고정. 학생이 임의 변경 불가.

학생 현황

📊

데이터 내보내기

전체 학생 점수·뱃지·최고기록을 CSV 파일로 저장. (게임방 전용)

🗑️

전체 초기화

모든 학생 데이터를 지웁니다. 새 학기나 다음 반 수업 전 사용.

🔗

두 앱이 데이터를 공유해요

놀이터와 게임방은 동일한 localStorage 키(eaim_english_)를 사용합니다. API 키, 비밀번호, 레벨 설정이 두 앱에서 공유됩니다.

GitHub Pages 배포

무료로 인터넷에 공개 · QR코드로 학생 접속 가능
📁 파일 구조
📁 리포지토리 루트/
├── index.html            ← 메인 허브 페이지
├── eaim-english-playground.html  ← 영어 놀이터
├── eaim-english-game.html    ← 영어 게임방
└── guide.html            ← 이 사용 가이드
🚀 GitHub Pages 배포 순서

GitHub 계정 로그인

github.com에 접속하여 로그인합니다. 계정이 없으면 무료로 만드세요.

New repository 생성

오른쪽 상단 + → New repository 클릭. Repository name에 원하는 이름 입력 (예: eaim-english). Public으로 설정.

파일 업로드

리포지토리 페이지에서 Add file → Upload files 클릭 후 HTML 파일 4개를 드래그앤드롭하여 올립니다.

GitHub Pages 활성화

리포지토리 상단 Settings → 왼쪽 Pages → Source를 Deploy from a branch, Branch를 main / (root)로 설정 후 Save.

URL 확인 & QR코드 생성

약 1~2분 후 Settings → Pages에서 URL이 표시됩니다.

https://[계정명].github.io/[리포지토리명]/

이 URL을 qr.io 등 무료 QR 생성 사이트에 넣으면 학생 배포용 QR코드 완성!

📱

모바일 최적화 완료

두 앱 모두 모바일(스마트폰·태블릿)에서 완벽하게 작동합니다. 학생들이 스마트폰으로 QR코드를 찍어 바로 접속할 수 있어요.

설치 없이 앱처럼 — Android · iOS · PC 모두 가능
📲 PWA란?

Progressive Web App의 줄임말로, 웹사이트를 스마트폰 홈 화면에 아이콘으로 저장해서 일반 앱처럼 실행하는 기술입니다. App Store나 Play Store에서 다운받을 필요 없이, QR코드 한 번으로 접속한 뒤 설치하면 끝입니다.

🤖 Android (크롬) 설치 방법

크롬으로 사이트 접속

QR코드를 스캔하거나 GitHub Pages URL을 크롬 브라우저로 열어요.

설치 배너 확인

화면 하단에 파란색 "홈 화면에 설치하기" 배너가 자동으로 나타납니다. "설치" 버튼을 탭하세요.

홈 화면 확인

EAIM 영어 플랫폼 아이콘이 홈 화면에 생성됩니다. 다음부터는 아이콘을 탭하면 앱처럼 바로 실행돼요!

💡

배너가 안 뜨면?

크롬 주소창 오른쪽 ⋮ 메뉴 → "홈 화면에 추가"를 선택해도 설치할 수 있어요.

🍎 iOS (Safari) 설치 방법

iOS Safari는 자동 배너가 뜨지 않아요. 아래 방법으로 수동 설치하세요.

Safari로 사이트 접속

반드시 Safari 브라우저를 사용해야 합니다. Chrome for iOS는 홈 화면 추가가 지원되지 않아요.

공유 버튼 탭

화면 하단 가운데 □↑ 공유 버튼을 탭합니다.

"홈 화면에 추가" 선택

공유 메뉴를 아래로 스크롤하면 "홈 화면에 추가" 항목이 있어요. 탭 후 오른쪽 위 "추가" 버튼을 누르세요.

👩‍🏫

수업 첫 날 5분 투자!

첫 수업에서 학생들과 함께 설치하는 시간을 가지면, 이후 매 수업마다 QR 스캔 없이 아이콘 탭 하나로 접속할 수 있어요.

💻 PC (크롬/엣지) 설치 방법

컴퓨터실 수업에서도 PWA로 설치하면 바탕화면 아이콘으로 실행 가능합니다.

크롬/엣지로 사이트 접속

GitHub Pages URL을 크롬 또는 Edge 브라우저로 엽니다.

주소창 설치 아이콘 클릭

URL 입력창 오른쪽 끝에 ⊕ 설치 아이콘이 나타납니다. 클릭 후 "설치"를 선택하세요.

바탕화면 아이콘 확인

바탕화면 또는 시작 메뉴에 EAIM 아이콘이 생깁니다. 이후 별도 브라우저 없이 앱처럼 실행돼요.

🔄 업데이트 안내

선생님이 GitHub에 파일을 수정·업로드하면, 학생 기기에 🔄 새 버전이 있어요! 초록 배너가 자동으로 표시됩니다. "업데이트" 버튼을 탭하면 최신 버전으로 갱신됩니다.

⚠️

파일 수정 후 캐시 갱신 방법

sw.js 파일 상단의 CACHE_VERSION = 'eaim-english-v1' 을 v2, v3... 으로 올려주면 학생 기기에 자동 업데이트 알림이 뜹니다.

교사 컨트롤 패널 → 레벨 고정 기능을 사용하세요. 레벨을 고정하면 학생 화면에서 레벨 변경 버튼이 잠기고 "선생님이 설정함" 표시가 나타납니다.
랭킹이 반 전체에 공유되지 않아요.
현재 버전은 localStorage 기반으로, 같은 기기·브라우저 내에서만 데이터가 공유됩니다. 학교 컴퓨터실처럼 각자 다른 기기를 사용하는 경우 각 기기에서 독립적으로 데이터가 저장됩니다. 교사는 CSV 내보내기로 전체 데이터를 통합 관리하세요.
소리(TTS)가 나오지 않아요.
크롬(Chrome) 브라우저를 사용하고 있는지 확인하세요. 일부 기기에서는 사용자의 첫 번째 클릭 이후에만 소리가 활성화됩니다. 볼륨이 음소거 상태가 아닌지도 확인해 주세요.
교사 비밀번호를 잊어버렸어요.
브라우저 개발자 도구(F12) → Application → LocalStorage에서 eaim_teacher_pw 항목을 삭제하면 기본값 1234로 초기화됩니다.
GitHub에 올렸는데 페이지가 열리지 않아요.
GitHub Pages 활성화 후 최대 10분 정도 시간이 소요될 수 있습니다. Settings → Pages에서 녹색 체크 표시와 함께 URL이 표시될 때까지 기다려 주세요.
Gemini API 비용이 발생하나요?
Google AI Studio의 무료 티어(Free tier)는 분당 15회 요청, 하루 1,500회 요청이 무료입니다. 일반적인 수업 활용 범위에서는 무료로 충분히 사용할 수 있습니다.
